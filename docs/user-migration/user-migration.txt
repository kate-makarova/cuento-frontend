[b]Миграция пользовательских данных[/b]

Функция миграции пользовательских данных позволяет перенести существующий эпизод ролевой игры с другой платформы (в настоящее время поддерживаются форумы на базе MyBB) в Cuento. Модуль получает оригинальные посты, даёт возможность сопоставить старые никнеймы с персонажами на вашем форуме и публикует весь тред в виде нового эпизода — с сохранением авторства, порядка и содержания.

Запустить миграцию может любой участник целевого эпизода. Процесс занимает несколько минут и не требует технических знаний — достаточно уметь открыть ссылку и скопировать текст.

[b]Как использовать миграцию пользовательских данных[/b]

[b]Шаг 1 — Подготовьте эпизод на своём форуме[/b]

Перед началом миграции создайте эпизод-приёмник на своём форуме Cuento и добавьте в него всех персонажей, которые писали посты в оригинальном треде. [b]Если хотя бы один участвующий персонаж отсутствует, миграция не сможет завершиться[/b] — сначала добавьте их в эпизод, затем вернитесь.

[b]Шаг 2 — Заполните форму миграции[/b]

Перейдите в раздел [b]Создать миграцию данных[/b]. Вы увидите короткую форму с четырьмя полями:

[list]
[*][b]Платформа[/b] — на данный момент поддерживается только MyBB; оставьте значение без изменений.
[*][b]Домен форума[/b] — домен форума-источника без [b]http://[/b] и без завершающего слеша (например, [b]dune.rusff.me[/b]).
[*][b]ID темы[/b] — откройте оригинальный тред в браузере и найдите в URL [b]?id=57[/b] или [b]topic=57[/b]; введите это число.
[*][b]Количество постов[/b] — общее число постов, указанное в оригинальном треде. Модуль достаточно умён, чтобы скорректировать значение, если вы ошиблись на единицу (вступительный пост иногда считается отдельно, поэтому не переживайте).
[/list]

Нажмите [b]Сгенерировать ссылку(и) для миграции[/b], когда все поля заполнены.

[b]Шаг 3 — Просмотрите страницу миграции и откройте ссылку для извлечения данных[/b]

После отправки формы вы окажетесь на странице деталей миграции. Здесь отображаются статус миграции (изначально [b]Ожидание[/b]), домен и ID темы, которые вы ввели, название оригинального треда, а также раздел [b]Ссылки для извлечения данных[/b] с одной или несколькими кликабельными ссылками.

Откройте каждую ссылку в новой вкладке браузера. На странице отобразится сырой JSON — это данные постов, экспортированных с форума-источника.

[b]Шаг 4 — Скопируйте и вставьте извлечённые данные[/b]

На странице с ссылкой для извлечения нажмите [b]Ctrl + A[/b], чтобы выделить весь текст, затем [b]Ctrl + C[/b], чтобы скопировать его.

Вернитесь на страницу миграции и вставьте скопированное содержимое в текстовое поле [b]Обработать данные[/b]. Если исходный тред занимает несколько страниц и вы получили несколько ссылок для извлечения, обрабатывайте их поочерёдно: вставьте содержимое первой страницы, нажмите [b]Обработать[/b], дождитесь результата, затем повторите для каждой следующей ссылки.

[img]PLACEHOLDER_03[/img]

Нажмите [b]Обработать[/b], чтобы отправить данные на сервер.

[b]Шаг 5 — Сопоставьте пользователей с персонажами и опубликуйте[/b]

После завершения обработки на странице появится сводка [b]Результатов обработки[/b] — количество найденных постов, пропущенных дубликатов и информация о том, все ли посты были разобраны — а также таблица [b]Сопоставление пользователей[/b].

В таблице в левом столбце отображаются никнеймы из оригинального форума. Используйте поле [b]Найти персонажа...[/b] в правом столбце, чтобы найти и выбрать соответствующего персонажа на вашем форуме Cuento. Сделайте это для каждой строки. Кнопка [b]Обновить сопоставление[/b] остаётся неактивной, пока каждому пользователю не будет назначен персонаж.

После сохранения сопоставления в нижней части страницы становится доступен раздел [b]Публикация[/b]. Выберите эпизод-приёмник и нажмите [b]Опубликовать[/b]. Посты будут созданы в эпизоде в их изначальном порядке.

[b]Примечания[/b]

[list]
[*][b]Заранее подготовьте всех персонажей.[/b] Если в процессе миграции выяснится, что какого-то персонажа нет в эпизоде, добавьте его на форум и вернитесь к завершению сопоставления.
[*]Количество постов может отличаться на единицу — модуль автоматически обнаруживает и корректирует разницу между учётом и неучётом вступительного поста.
[*]Для тредов, охватывающих несколько страниц, вы получите по одной ссылке для извлечения на каждую страницу. Вставляйте и обрабатывайте каждую страницу по порядку перед публикацией.
[*]После публикации миграции её статус меняется на [b]Опубликовано[/b] и запустить её повторно для той же записи невозможно.
[/list]
